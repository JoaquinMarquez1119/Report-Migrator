# Checklist de artefactos

## Minimo indispensable

- `inputs/xml-spec/` o archivo `XML Spec.xml`
- `inputs/queries/`
- PDF del reporte original
- screenshots de referencia

## Muy recomendados

- mappings funcionales previos
- notas de negocio
- assets como logos o imagenes
- evidencia de validacion ya existente
- reporte relacionado base o drill-through si forman una familia

## Preguntas previas a construir

- Cuales son los parametros reales y sus defaults
- Que dataset alimenta cada parte visible
- Que ramas funcionales existen
- Que columnas cambian segun familia o unidad
- Que reglas de visibilidad no se pueden perder
- Como se valida el resultado contra Cognos
