# Migration Retrospective

## When to use

Usar al cerrar una migracion o cuando aparece un problema nuevo que probablemente vuelva a repetirse.

## Checklist

- Registrar el problema real y su causa raiz.
- Registrar la correccion aplicada.
- Decidir si la leccion es local, familiar, reusable o automatizable.
- Si es reusable, moverla a `knowledge/`.
- Si es automatizable, moverla a `tools/`.
- Si define un procedimiento repetible, convertirla en skill local.
